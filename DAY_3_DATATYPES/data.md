# Python Data Types

A **data type** defines the kind of value a variable holds. In Python, the data type is set automatically when you assign a value to a variable — no explicit declaration needed. 

---

## Overview
 
| Data Type | Category | Mutable | Example |
|-----------|----------|---------|---------|
| `str` | Text | No | `"hello"` |
| `int` | Numeric | No | `42` |
| `float` | Numeric | No | `3.33` |
| `complex` | Numeric | No | `1j` |
| `list` | Sequence | Yes | `["a", "b"]` |
| `tuple` | Sequence | No | `("a", "b")` |
| `range` | Sequence | No | `range(0, 7)` |
| `dict` | Mapping | Yes | `{"key": "value"}` |
| `set` | Set | Yes | `{"a", "b"}` |
| `frozenset` | Set | No | `frozenset({"a", "b"})` |
| `bool` | Boolean | No | `True` |
| `bytes` | Binary | No | `b"hello"` |
| `bytearray` | Binary | Yes | `bytearray(5)` |
| `memoryview` | Binary | No | `memoryview(b"hello")` |
